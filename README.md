# Aakash Siricilla — Agents that act. Systems that hold.

Personal site for a software engineer who builds **LLM agents that operate real software** and the **distributed systems** underneath them.

Live: https://aakashsiricilla-portfolio.vercel.app/

## The idea

Computer-use agents look at screens, so this site has two viewers, a human and an agent.

- **Human view.** Paper, ink, and a big editorial serif. This is Aakash talking.
- **Agent view.** The same live page the way an agent perceives it: inverted, drained of colour, with a detection box, role, confidence score, and click coordinates on every element. Press **V** (or use the Human / Agent switch) at any time.

The page boots in agent view and scans into the human view. An agent cursor ("Astra") then works the hero. It uses speed-and-separation monitoring, like a collaborative robot: move your mouse near it and it stops, steps back, and waits.

## Build

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production bundle in dist/
npm run lint
```

Stack: React 19 + Vite 7, hand-written CSS, and self-hosted fonts (Instrument Serif, Geist, Geist Mono via Fontsource). There is no animation or UI library. Every motion is written by hand: minimum-jerk cursor paths, canvas renderers, CSS transitions.

## Editing content

All copy, numbers, and links live in **`src/data/content.js`**. Every figure there comes from the résumé (`public/Aakash_Resume.pdf`).

- **Tag an element for agent vision:** add `data-agent="heading" | "text" | "link" | "button" | "metric" | …`. Anything tagged gets a box in agent view. Links, buttons, and form fields are labelled with click coordinates.
- **Portrait:** `src/data/asciiPortrait.js`, generated by `scripts/ascii_portrait.py` from a photo.
- **Share image:** `public/og.png`, a capture of the boot scan mid-sweep.

## Structure

```
src/
  data/          content + portrait data
  lib/           store (vision state), motion (minimum-jerk glide), hooks
  styles/        design tokens, type, shared keyframes
  components/
    VisionLayer   the agent's view: backdrop-filter + per-frame detection boxes
    HeroAgent     the cursor in the hero, and its safety-radius yielding
    AstraDemo     the scripted run + approval gate + audit receipt
    Stream        the 1-dot-per-event pipeline canvas
    Portrait      the scanline engraving
    …             one component + stylesheet per section
```

## Accessibility

- Honors `prefers-reduced-motion`: no boot scan and no roaming cursor. The stream is a still frame, and the demo runs on a click and steps instantly to the gate.
- Decorative agent layers are `aria-hidden`. The approval gate is a real `alertdialog` with focus management, and demo outcomes are announced.
- Keyboard: <kbd>V</kbd> toggles agent vision, <kbd>Esc</kbd> returns to the human view.
